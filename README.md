## Langkah-Langkah Pengerjaan

Ikuti alur pengerjaan tugas secara berurutan berikut:

1. **Persiapan Akun**  
   Buat/gunakan akun GitHub pribadi dengan **nama asli** agar panitia dapat mengenali pembuat berkas.

2. **Fork Repositori**  
   Lakukan **Fork** pada repositori ini ke akun GitHub pribadi kamu dengan mengeklik tombol `Fork` di pojok kanan atas halaman.

3. **Buka Repositori Hasil Fork**  
   Akses repositori yang telah di-*fork* di akun GitHub milikmu (URL akan berbentuk `github.com/username-kamu/MABA-STATIK-2026`).

4. **Navigasi ke Folder Kelompok**  
   Masuk ke dalam folder yang sesuai dengan kelompok kamu (contoh: folder `Aethron/`).

5. **Buat Berkas Baru**  
   Di dalam folder kelompokmu, klik **Add file** $\rightarrow$ **Create new file**.

   NIM-NamaLengkap.md
