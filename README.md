## Cara Mengerjakan

Buat akun GitHub menggunakan nama asli.

Lakukan Fork repository ini ke akun GitHub pribadi.

Buka repository hasil Fork pada akun GitHub masing-masing.

Masuk ke folder sesuai dengan kelompok masing-masing.

Buat file baru dengan format:

NIM-NamaLengkap.md
Contoh:

240601001-BudiSantoso.md
Isi file tersebut dengan format berikut:

# Biodata

- **Nama Lengkap:**
- **NIM:**
- **Tanggal Lahir:**
- **Tujuan Masuk Teknik Informatika:**
- **Bidang di Dunia IT yang Ingin Didalami:**
- **Fun Fact:**
Setelah selesai mengisi biodata, klik Commit changes.

Buat Pull Request (PR) ke repository utama.

Format Judul Pull Request
Gunakan format berikut:

[NIM] Nama Lengkap - Kelompok XX
Contoh:

[240601001] Budi Santoso - Kelompok 01
Ketentuan
Gunakan akun GitHub dengan nama asli.
Peserta wajib melakukan Fork repository sebelum mengerjakan penugasan.
Hanya diperbolehkan menambahkan file pada folder kelompok masing-masing.
Dilarang mengubah, memindahkan, atau menghapus file milik peserta lain.
Nama file wajib mengikuti format NIM-NamaLengkap.md.
Pastikan biodata telah diisi dengan lengkap dan benar sebelum melakukan Commit.
Setiap peserta hanya diperbolehkan mengirim satu (1) Pull Request (PR).
Apabila terdapat kesalahan atau kendala setelah Pull Request dikirim, peserta tidak diperkenankan membuat Pull Request baru. Peserta wajib menghubungi Divisi Penugasan untuk mendapatkan arahan lebih lanjut.
Pull Request yang tidak sesuai dengan ketentuan dapat ditolak (Closed) oleh panitia dan peserta wajib melakukan perbaikan sesuai arahan.
Penutup
Pastikan seluruh langkah telah dilakukan sesuai dengan ketentuan yang berlaku sebelum mengirimkan Pull Request. Apabila terdapat pertanyaan atau kendala selama pengerjaan, silakan menghubungi Divisi Penugasan.

Lihat panduan lengkap di README masing-masing folder kelompok (Fork → isi biodata → Pull Request).
