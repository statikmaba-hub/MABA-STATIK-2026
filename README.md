## Langkah-Langkah Pengerjaan

Ikuti instruksi pengerjaan secara berurutan berikut dengan teliti:

### 1️ Persiapan Akun
Gunakan atau buat akun GitHub pribadi dengan **nama asli** (bukan nama samaran) agar panitia dapat memverifikasi identitas pemilik berkas.

### 2️ Fork Repositori
Lakukan **Fork** pada repositori ini ke akun pribadi kamu dengan mengeklik tombol **`Fork`** (di pojok kanan atas halaman ini).

### 3️ Buka Repositori Hasil Fork
Buka repositori yang sudah di-*fork* pada akun GitHub pribadimu (URL akan berbentuk: `github.com/username-kamu/MABA-STATIK-2026`).

### 4️ Masuk ke Folder Kelompok
Klik dan masuk ke dalam folder sesuai dengan nama kelompokmu (Contoh: folder `Aethron/`).

### 5️ Buat Berkas Biodata Baru
Di dalam folder kelompokmu:
* Klik tombol **Add file** ➔ **Create new file**.
* Beri nama berkas baru tersebut dengan format wajib:
  ```text
  NIM-NamaLengkap.md
  ```
  *Contoh Penamaan File:* `240601001-BudiSantoso.md`

### 6️ Isi Template Biodata
Salin (*copy*) dan tempel (*paste*) kode markdown berikut ke dalam berkas barumu, lalu lengkapi isinya:

```markdown
### Biodata Anggota

* **Nama Lengkap:** 
* **NIM:** 
* **Asal Daerah / Kota:** 
* **Tujuan Masuk Teknik Informatika:** 
* **Bidang IT yang Ingin Didalami:** 
* **Fun Fact:** 
```

### 7️ Simpan Perubahan (Commit Changes)
Setelah seluruh biodata terisi dengan benar, simpan berkas dengan mengeklik tombol **Commit changes...** di pojok kanan atas.

### 8️ Kirim Pull Request (PR)
* Kembali ke repositori utama penugasan angkatan (`MABA-STATIK-2026`).
* Masuk ke tab **Pull Requests** ➔ klik **New pull request** (atau klik tombol **Contribute** ➔ **Open pull request** dari repositori hasil fork kamu).
* Beri judul Pull Request sesuai format resmi di bawah ini.

#### Format Judul Pull Request
Gunakan format udul wajib berikut saat mengajukan Pull Request:

```text
Nama Lengkap (NIM) - Nama Kelompok
```
*Contoh Judul PR:* `Budi Santoso (240601001) - Aethron`

## Ketentuan & Aturan Penting

* **Identitas Akun:** Wajib menggunakan akun GitHub dengan nama asli yang mudah dikenali.
* **Wajib Fork:** Pengerjaan berkas harus dilakukan di dalam repositori hasil Fork pribadi, bukan secara langsung di repositori utama.
* **Isolasi Folder:** Setiap peserta hanya diperbolehkan menambahkan 1 file di dalam folder kelompoknya masing-masing.
* **Integritas Berkas:** Dilarang keras mengedit, memindahkan, atau menghapus berkas milik peserta lain.
* **Format Penamaan:** Nama file wajib mengikuti format `NIM-NamaLengkap.md`.
* **Batas Pengajuan PR:** Setiap peserta hanya diperbolehkan mengirim satu (1) Pull Request.
* **Penanganan Kesalahan Data:** Jika terdapat kesalahan penulisan atau kendala setelah PR dikirim, **DILARANG** menutup (*Close*) PR atau membuat PR baru. Segera hubungi Divisi Penugasan untuk arahan perbaikan.
* **Sanksi/Penolakan:** Pull Request yang tidak memenuhi ketentuan di atas dapat ditolak (*Closed*) oleh panitia.
